🦸‍♂️ HeroFit AI

Treinos personalizados gerados por inteligência artificial

HeroFit AI é uma aplicação web que cria planos de treino personalizados com base no perfil, objetivos e rotina do usuário.
A ideia é transformar fitness em uma experiência simples, motivadora e gamificada.

✨ Funcionalidades

📝 Formulário de perfil do usuário
🎯 Geração de plano de treino personalizado
🤖 Uso de inteligência artificial para criar rotinas
📅 Treino organizado por dias da semana
📊 Interface moderna com visual de dashboard fitness
🦸 Sistema de “missões” para motivação

🧠 Ideia do projeto

O HeroFit AI transforma treinos em uma jornada estilo “super-herói”, onde cada usuário evolui completando missões físicas baseadas no seu objetivo.

🛠️ Tecnologias utilizadas

HTML / CSS / JavaScript (ou stack gerada pelo Lovable)
IA Generativa
Design responsivo
UI moderna inspirada em apps fitness e SaaS

🎯 Objetivo

Facilitar o acesso a treinos personalizados e motivar pessoas a manterem uma rotina saudável com ajuda de IA.
